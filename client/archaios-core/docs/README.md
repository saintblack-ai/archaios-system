# ARCHAIOS Runtime Docs

This folder contains canonical documentation for `client/archaios-core/`.

Files:

- `runtime-map.md`: runtime ownership, health, and folder responsibilities.
- `agent-map.md`: agent manifests, scripts, outputs, and dependencies.
- `service-map.md`: service registry and service dependency boundaries.
- `canonical-paths.md`: official runtime path decisions and duplicate path references.
- `migration-readiness.md`: migration recommendations, risk, and readiness scoring.

These documents are preparation artifacts only. They do not move, rename, delete, archive, deploy, or mutate runtime files.
