# Archaios Legacy Protocol

**Objective:** Preserve the intellectual, technical, creative, and personal record for at least 100 years without depending on any single vendor, account, or person.

## Preservation Standard

1. Keep the original file, a preservation copy, and a human-readable derivative when practical.
2. Use durable formats: UTF-8 Markdown/TXT, PDF/A where available, CSV, JSON, SQL, WAV/FLAC, TIFF/PNG, MP4/MKV, and source code with Git history.
3. Store a manifest for every collection: title, creator, date, rights/ownership, source, sensitivity, file hash, format, location, and restoration instructions.
4. Use 3-2-1 storage: three copies, two media/provider types, one offline/offsite copy. Encrypt sensitive personal material.
5. Verify checksums annually and conduct a restoration drill quarterly.

## Knowledge And Research Preservation

| Collection | Canonical record | Preservation action |
| --- | --- | --- |
| Archaios research | Research entries, sources, evidence, claims, timelines | Export to Markdown/JSON with source URLs, timestamps, confidence, counterarguments, and related research. |
| Personal journals | Original scans/text plus metadata | Keep encrypted originals, a redacted access copy, and clear embargo instructions. |
| Military history | Source documents, citations, rights notes | Preserve provenance and distinguish source material from interpretation. |
| Research archives | Raw source, notes, analysis, conclusion | Never store conclusions without the supporting source trail. |

## Black Vault Preservation

1. Maintain a Black Vault index in Git-friendly Markdown and a separate encrypted content archive for sensitive files.
2. Give every item a stable identifier; do not use a cloud folder name as its only identity.
3. Keep a quarterly export of Notion indexes, but keep primary source files outside Notion.
4. Store a read-only annual snapshot with checksum manifest, collection map, and recovery instructions.
5. Restrict access by sensitivity class: public, internal, confidential, personal, sealed/embargoed.

## QX Technology Preservation

1. Preserve the full Git repository, release artifacts, architecture manuals, environment-variable inventory without values, database migration manifest, and deployment records.
2. Record platform accounts, project IDs, domains, and renewal owners in the encrypted access inventory, never in source control.
3. Export database schema and non-secret configuration each month; export operational data according to retention policy and consent obligations.
4. Preserve worker and frontend build instructions so the system can be reconstructed without a hosted dashboard.

## Saint Black Creative Preservation

1. Separate masters, working sessions, lyrics/writing, artwork, release metadata, contracts, and rights documentation.
2. Preserve original audio masters in lossless form, plus listening derivatives and a work-level metadata record.
3. Include authorship, contributors, splits, identifiers, release dates, permissions, and contact information for every creative work.
4. Keep personal journals and unreleased work encrypted with explicit access and embargo conditions.

## Family Transfer Instructions

1. Maintain a sealed, dated `Legacy Access Letter` outside the repository naming the executor/successor, emergency contacts, storage locations, recovery order, and legal adviser. Do not include passwords in the letter.
2. Store account recovery codes and credentials in a reputable encrypted password manager with an emergency-access process, plus a separate offline recovery copy.
3. Provide successors with a plain-language collection map, a list of active subscriptions/renewals, ownership notes, and the location of the latest verified backup.
4. Review the transfer package annually and after any major account, relationship, or ownership change.
5. Obtain qualified legal advice for wills, trusts, copyright transfer, beneficiary designations, and privacy obligations. This protocol is operational guidance, not legal advice.

## Annual Legacy Audit

- [ ] Hash verification passed for the archive.
- [ ] At least one full restore was opened and checked.
- [ ] Git mirror and offline copy exist.
- [ ] Notion export is complete and readable outside Notion.
- [ ] QX technical instructions build from the archived source.
- [ ] Creative works have ownership and metadata records.
- [ ] Successor instructions are current and accessible to the designated person.
