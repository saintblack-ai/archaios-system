# AI Assassins User Guide

**Audience:** Customers, testers, support  
**Related:** [Customer Onboarding Guide](CUSTOMER_ONBOARDING_GUIDE.md), [Product Vision](PRODUCT_VISION.md), [Version 1.0 Release Notes](VERSION_1_RELEASE_NOTES.md)

## Executive Summary

AI Assassins is the user-facing ARCHAIOS experience for command dashboards, task execution, knowledge workflows, revenue visibility, and AI-assisted operations. The product is designed for operators who need clarity, not noise.

## Core Concepts

| Concept | Meaning |
| --- | --- |
| Dashboard | Main operating screen |
| Commander | Executive summary and prioritization layer |
| Mission Queue | Work items and operational tasks |
| Knowledge Base | Organized memory and documents |
| Revenue View | Pricing, subscription, and business signals |
| Agent Reports | Structured outputs from AI subsystems |

## Getting Started

1. Open the production frontend.
2. Review the dashboard shell.
3. Sign in with Supabase Auth.
4. Select plan if paid access is required.
5. Complete checkout if available.
6. Return to dashboard.
7. Review Commander brief.
8. Add or inspect tasks.

## User Workflows

### Review Daily Status

- Open dashboard.
- Read Commander summary.
- Review active projects.
- Check task queue.
- Choose one priority action.

### Use Knowledge

- Open knowledge section.
- Search relevant documents.
- Review source metadata.
- Capture decisions back into the Black Vault.

### Manage Revenue

- Open pricing or revenue view.
- Confirm current plan.
- Review subscription state.
- Contact support if billing status is wrong.

## Troubleshooting

| Symptom | Likely Cause | Action |
| --- | --- | --- |
| Cannot sign in | Auth issue | Retry, then contact support |
| Checkout unavailable | Signed out or billing disabled | Sign in and retry |
| Dashboard loads but data missing | Backend or Supabase issue | Check status page or support |
| Subscription not reflected | Webhook sync delay | Wait, then contact support |
