## Executive Summary

ARCHAIOS exists to give its founder a durable operating system for memory, execution, intelligence, revenue, and creative command. The founder role is not to manually track every task. The founder role is to set intent, approve high-risk actions, protect the mission, and use Commander to keep the system honest.

## Founder Operating Doctrine

1. Prefer verified operational truth over momentum.
2. Revenue, security, and reliability outrank feature expansion.
3. Do not deploy from uncertainty.
4. Keep decisions in the Black Vault.
5. Protect creative time as a strategic asset.
6. Preserve the system for future operators.

## Founder Checklists

### Before Approving Production Work

- [ ] Current readiness score reviewed
- [ ] Git status understood
- [ ] Secrets not exposed
- [ ] Rollback path documented
- [ ] Production owner identified
- [ ] One change at a time

### Before Stepping Away

- [ ] Session handoff exists
- [ ] Next mission named
- [ ] Blockers listed
- [ ] No unapproved deploy pending
- [ ] Creative work protected
