# Customer Onboarding Guide

**Audience:** New customers, support, customer success  
**Related:** [AI Assassins User Guide](AI_ASSASSINS_USER_GUIDE.md), [Admin Operations Guide](ADMIN_OPERATIONS_GUIDE.md), [Product Vision](PRODUCT_VISION.md)

## Executive Summary

Customer onboarding should get a user from first login to first useful Commander brief as quickly as possible. The goal is activation, not feature explanation.

## Onboarding Outcomes

| Outcome | Success Signal |
| --- | --- |
| Account created | User can sign in |
| Plan selected | User understands Free, Pro, Elite |
| Dashboard opened | User sees command surface |
| First objective captured | User has one active mission |
| First value delivered | User receives a useful brief or task plan |

## First Session Flow

1. Welcome user.
2. Confirm account access.
3. Confirm plan tier.
4. Show dashboard.
5. Capture one objective.
6. Generate or review Commander brief.
7. Identify next action.
8. Confirm support path.

## Customer Success Checklist

- [ ] User can sign in
- [ ] User knows current plan
- [ ] User sees dashboard
- [ ] User has one mission or objective
- [ ] User understands where to find tasks
- [ ] User knows how to request support
- [ ] Billing status is correct

## Support Intake

| Issue Type | Required Information |
| --- | --- |
| Login | Email, timestamp, browser |
| Billing | Plan, Stripe receipt or invoice ID |
| Dashboard | Page, timestamp, screenshot if safe |
| Data issue | Expected value, observed value |
| Feature request | Desired outcome, business reason |
